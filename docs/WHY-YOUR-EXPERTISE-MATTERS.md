# Why your expertise matters to StrataMesh

**Pre-testnet laboratory.** We invite technically serious people while the substrate is still being shaped — not to implement a finished chain.

You do **not** need to learn “all of StrataMesh” first. Find the row that matches what you already ship.

| You already work on | Where you fit | Start here |
|---------------------|---------------|------------|
| **Distributed systems / P2P / libp2p** | GDA gossip, peer coordination, fault tolerance | Issues `track:network` · [WANTED](./WANTED.md) |
| **Edge / Fog / KubeEdge / Akri / EdgeX** | Heterogeneous devices as computational resources | Issues `track:edge` |
| **Decentralized compute (Golem, Akash)** | Contribution ↔ subsistence ↔ settlement realism | Issues `track:economy` |
| **IPFS / content addressing** | Distributed objects, availability, retrieval | `track:network` / core docs |
| **DAG / IoT / machine economy (IOTA-class)** | Adjacent ledger + device coordination | `track:core` · `track:edge` |
| **Kubernetes / orchestration** | Scheduling, failure recovery, multi-host ops | `track:edge` · ops scripts |
| **Agent frameworks (LangGraph, AG2, …)** | SCA lifecycle, persistence, multi-agent | Issues `track:agents` |
| **Godot / Bevy / simulation** | Virtual Domains → Open Worlds → CGU | Issues `track:worlds` |
| **Security / adversarial testing** | Attack the protocol **before** testnet | Issues + lab ladder |
| **Identity / DID** | Subjects, standing, clearance honesty | Issues `track:identity` |
